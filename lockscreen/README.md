# Nothing Interface: блокировка и экран входа

Тема работает на экране блокировки Ryoku и в SDDM. В сеансе она получает обои и
сведения виджетов напрямую от Ryogami и Ryoku. При загрузке SDDM использует
последнюю сохранённую копию обоев, доступную до входа в пользовательский сеанс.

## Установка экрана входа с сохранением обоев

На Ryoku нужны `python3`, `python-pillow`, SDDM и штатный `ryoku-hub`.
Из корня этого репозитория запустите от обычного пользователя:

```bash
bash lockscreen/install-greeter.sh
```

Установщик запросит системную авторизацию, подготовит отдельную папку обоев,
выберет тему штатной командой Ryoku и включит службу пользователя. Текущий сеанс
продолжит работать; новый экран входа появится при следующем входе в систему.

Служба `nothing-greeter-wallpaper.service` подписывается на события Ryogami.
Она записывает декодированное изображение без метаданных в
`/var/lib/ryoku/nothing-interface/background/current.png`. При смене обоев файл
обновляется атомарно; при выключении службы или ошибке исходного изображения
сохраняется последняя исправная копия. Для видеообоев сохраняется изображение,
которое Ryogami публикует в поле `path`, — статичный фон для экрана входа.

SDDM видит только эту общедоступную копию, ему не предоставляется доступ к
домашнему каталогу. Служба работает от пользователя, а права администратора
нужны один раз для подготовки папки и применения темы. На машине с несколькими
пользователями папка принадлежит пользователю, который настроил синхронизацию;
другому пользователю установщик не передаёт её автоматически.

## Управление

- Пароль отправляется по Enter или кнопке со стрелкой. Подсказка про Enter скрыта;
  ошибка пароля отображается как раньше.
- Выключение и перезагрузка требуют подтверждения. Сон использует штатный вызов
  SDDM, а в сеансе — безопасный механизм сна Ryoku.
- На экране входа меню «Окружение» перечисляет установленные сеансы. Выбранный
  пункт передаётся SDDM при входе; SDDM запоминает последний успешный сеанс.
- На обычной блокировке выбор окружения скрыт: разблокировка возвращает в текущий
  сеанс. Кнопки питания доступны на обоих экранах.
- Медиа и время активности читаются из пользовательского сеанса. До входа
  эти виджеты не показывают личные данные.

Для смены темы откройте **Ryoku Hub → Lockscreen**. Синхронизация обоев сама по
себе не выбирает тему заново и не изменяет обои рабочего стола.

## Проверки для разработчиков

```bash
python3 -m unittest discover -s lockscreen/tests -p 'test_*.py' -v
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software QT_QUICK_CONTROLS_STYLE=Basic \
  /usr/lib/qt6/bin/qml lockscreen/tests/verify-greeter.qml -- \
  --background file:///absolute/path/to/wallpaper.png --output /tmp/nothing-greeter.png
```

QML-проверка использует фиктивный интерфейс SDDM: проверяет сохранённый фон,
выбор сеанса, ошибку пароля и подтверждение питания, создаёт предпросмотр
1920×1080. Она не выключает компьютер и не отправляет настоящие учётные данные.
